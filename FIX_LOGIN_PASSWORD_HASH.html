Troubleshooting

If debug/users page shows RED for password matches:

  1. The hashes in the database are wrong
  2. Copy the correct hashes from debug/generate-password
  3. Run the SQL UPDATE statements
  4. Refresh the debug/users page to verify (should turn GREEN)

If you see "NO USERS FOUND IN DATABASE":

  1. Run this SQL first:
